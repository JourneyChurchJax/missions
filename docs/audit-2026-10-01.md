# Journey Missions: what's left from the October 1 audit

Updated October 2, 2026. The original list had 109 items. Everything that could be fixed in code has been fixed and tested, and those items were removed from this list.

What's left needs you: an account, a decision, a key, or a professional review. Numbers match the original audit.

---

## Do first (before real travelers, parents or donors use it)

1. **Move `config.php` out of `public_html`** (#36). Put it in the `missions.journeychurch.org` folder next to `public_html`. Settings shows a red warning until it's moved.
2. **Add the new settings to `config.php`** (see the README for the full example):
   - `alert_email`: where error and payment alerts go.
   - `cron_key`: any long random string.
   - `church_legal_name`, `church_address`, `church_ein`: printed on tax statements (#9).
   - `site_url`: `https://missions.journeychurch.org`.
3. **Back up the encryption key.** Passport numbers and medical notes are now encrypted. The key is in `data/secret.key` on the server (or put your own in `config.php` as `data_key`). Save a copy somewhere safe, like your password manager. Without it, those fields can't be read back.
4. **Mark yourself as staff.** Staff is no longer decided by email. Either add your Planning Center person ID to `staff_pco_ids` in `config.php`, or turn on "Staff access" on your person page in the app.
5. **Turn on the nightly job** (#6). SiteGround → Devs → Cron Jobs, once a night (the exact line is in the README). It sends queued messages, makes the nightly backup and erases old medical data.

## Needs a professional

6. **CPA or attorney: gift wording** (#9). The site now says the church controls all gifts and a traveler's name is only a preference, statements have the "no goods or services other than intangible religious benefits" wording, and the "deposit is tax-deductible" option is gone. Still needed:
   - A CPA to approve the wording.
   - A written policy for leftover money and travelers who drop out. Once it exists, it can be linked from the give page.
   - A decision on whether parents giving to their own child get a receipt.
7. **Lawyer: the waivers** (#5). Signatures now save a fingerprint of the document, lock it once signed, email the signer a copy, and parents confirm with a one-time code. A lawyer still needs to review the waiver text itself, and you need a medical-treatment permission form.

## Needs an account or a key

8. **Email service** (#45). Sign up for Postmark or Amazon SES, verify journeychurch.org (SPF and DKIM), and add the `smtp` settings to `config.php`. Until then, PHP mail is likely to land in spam. The send queue, retries and bounce alerts are already built.
9. **Texting registration** (#46). Register the Twilio number for A2P 10DLC, then add the `twilio` settings and point Twilio's incoming webhook at `/twilio-inbound.php`. Consent, STOP and HELP replies, and quiet hours (8am–9pm) are already built.
10. **Off-site backups** (#6). Nightly database backups are kept on the server for 30 days, but nothing leaves the server yet. Pick a place (Backblaze B2, Google Drive, Dropbox) for a weekly copy of `data/backups/` and `data/uploads/`. Then do one test restore (steps are in the README).
11. **Stripe** (#10–#21). All the money fixes are done and tested. When you have Stripe: add the keys, create the webhook with the 8 events listed in the README, and send a $1 test gift.
12. **Planning Center** (#3). Sign-in now matches only by Planning Center ID, and the first sign-in confirms with an emailed code. Add the PCO keys to turn it on.
13. **Spam protection, optional** (#31). Rate limits are on. For extra protection, add free Cloudflare Turnstile keys to `config.php`.
14. **Uptime monitor, optional** (#47). Point a free monitor (UptimeRobot) at `/health.php` so you hear about downtime.

## Needs real content from you

15. **Fill in the Belize trip details** (#54). Placeholder text like "[Airport: add details]" is now hidden from travelers, so those spots show nothing. Add the real airport, lodging and contact details in the trip's Travel and Guide tabs.
16. **Logo as SVG** (#90). The logo is still a PNG. If you have the SVG from the brand files, drop it in `public/assets/logo/` and it can be switched over.

## Bigger decisions (not urgent)

17. **Staging site** (#43). A copy at something like `staging.missions.journeychurch.org` to try changes before they go live. Needs a SiteGround subdomain and a second deploy target. Deploys now run a full check first and stop if anything fails, but FTP still uploads file by file. A staging site plus a switch-over deploy would fix that.
18. **Money stored as cents** (#17). Amounts are rounded to two places everywhere and it's accurate today. Switching to whole cents is a large change and only worth doing before a lot of real data exists.
19. **Design taste calls** (#62, #83, #84). Mobile layouts, focus outlines, tap sizes, buttons, headings and labels are fixed. Still your call: less ember red, less black, and one consistent meaning for the black pill.
20. **Cleaner code for a future developer** (#63, #106). Inline styles are down from 591 to about 390. `action.php` is organized and documented but is still one big file. Splitting it up is worth doing if someone else will maintain it.
21. **MySQL, multi-church, dark mode** (#95, #108, #109). Only if you ever want them.
